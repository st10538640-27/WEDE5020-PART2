# Toyota Corolla Workshop Website

## Project Overview

This website was created for the Toyota Corolla Workshop as part of
a web-development project.

The website provides information about vehicle maintenance, workshop
services, the gallery and contact details.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Responsive media queries
- Visual Studio Code
- GitHub

## Website Pages

- `home.html` – Website introduction and main services.
- `about.html` – Information about the workshop.
- `services.html` – Services provided by the workshop.
- `gallery.html` – Images related to vehicle maintenance.
- `contact.html` – Contact information and contact form.

## How to Run the Website

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension.
3. Open `home.html`.
4. Right-click inside the file.
5. Select **Open with Live Server**.
